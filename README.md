# ChainChip · выпуск 65

[Презентация проекта](https://b0ttokyanpa.github.io/chainchiprfq/?v=20261117-65#moysklad) · [Открытая демонстрация](https://demo.chainchiprfq.ru/) · [Инструкция выпуска 65](assets/user-guide-65.md)

Статическая презентация основного приложения: Excel клиента → RFQ → предложения → согласованный Анализ → КП → подтверждение продажи → закупка и PO → связанные документы МойСклада.

## Выпуск 65

- Следующее действие и маршрут заявки показываются в карточке. Состояние заказов обновляется автоматически рядом с продажей и PO, без перезагрузки форм.
- ОЗ подтверждает цену и срок у выбранного предложения; очередь цен есть в рабочем списке.
- Подтверждение продажи запускает создание заказа покупателя. Готовый PO — заказа поставщику и связанного счёта. КП само по себе заказ не создаёт.
- К заказу покупателя прикрепляются PDF КП и доступный клиентский Excel именно по согласованному Анализу продажи. К заказу и счёту поставщика прикрепляется переданная версия PO. История файлов сохраняется; внутренний Анализ не передаётся.
- Товары синхронизируются с МойСкладом в обе стороны. Остатки и DC видны в заявке, с разделением складов и резервов.
- Контрагенты сопоставляются администратором с проверкой названия/ИНН. Первоначальная настройка организации, складов и НДС остаётся отдельным действием администратора.
- Приёмки, оплата, резервы и отгрузки ведутся в МойСкладе. Интеграции с 1С нет; автоматизация согласования PO в Битриксе остаётся планом.

## Состояние иллюстраций и демонстрации

Презентация обновлена **после подготовки и проверки выпуска 65 основного приложения**. Состояния документов МС на них подменены для проверки интерфейса; реальные финансовые документы МС не создавались. Остальные снимки относятся к отдельной демонстрационной сборке 49 от 11.11.2026.

Открытая демонстрация устанавливается отдельно и может отличаться. В ней используются вымышленные данные и подготовленные результаты поиска, боевой обмен не включён. Обновление этой страницы не устанавливает приложение на VPS и не подтверждает его версию.

## Проект

C# / ASP.NET Core .NET 10, EF Core, SQL Server, ClosedXML и PDFsharp; HTML, CSS, JavaScript. Приложение запускается через systemd на Ubuntu за Nginx, SQL Server — в Docker. SQLite используется для демо и части тестов. Исходники основного приложения и его пакеты хранятся отдельно.

Возможности до 65: нормализация клиентских Excel и сохранение исходника; явные аналоги; сохранённые версии Анализа и КП; дневной курс ЦБ + 3 ₽; общий коэффициент наценки и исключения; обратная загрузка изменённого Анализа; сравнение предложений; история цен; частичные продажи, закупочные партии и PO; отчёты и история действий сотрудников; две темы и мобильный интерфейс.

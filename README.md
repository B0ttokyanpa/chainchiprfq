# ChainChip

Веб-приложение для продаж и закупок электронных компонентов: запрос клиента в Excel, предложения поставщиков, согласование ответа, продажа частями и заказ поставщику.

**[Страница проекта](https://b0ttokyanpa.github.io/chainchiprfq/)** · **[Открыть приложение](https://demo.chainchiprfq.ru/)**

Для просмотра выберите роль. Пароль не нужен. Данные вымышленные, общая песочница периодически очищается.

## Что делает приложение

- Создаёт заявки через конструктор или импорт из Excel; показывает ошибки обработки.
- Разделяет действия продаж, закупок и руководителя.
- Различает запросы (КП / НМЦ), тендеры и заказы; фильтрует списки и предпросмотры.
- Показывает поставщиков в общей таблице, MIN / MAX / медиану и предупреждения о необычных ценах.
- Ищет предложения для всех или выбранных позиций по кнопке; результаты добавляются в расчёт отдельным действием.
- Сохраняет версии предложений, показывает изменения и требует пересогласования новых условий.
- Переносит выбранную цену в новый Анализ; без явного выбора использует медиану.
- Собирает подтверждённые покупки и файлы в общем справочнике клиентов.
- Формирует собственные отчёты сотрудников и отчёты руководителей по сотруднику или отделу, на экране и в XLSX.
- Формирует Excel-ответы и версии заказов PO.
- Учитывает частичные продажи, закупочные партии и историю отмен.
- Поддерживает вложенные заявки, резервирование количества и время первого ответа по Москве.
- Отделяет навигацию кабинета от вкладок заявки; поддерживает две темы и доступное управление клавиатурой.

Страница и снимки обновлены под выпуск 39. Для https://demo.chainchiprfq.ru подготовлен отдельный пакет 39; он устанавливается на Timeweb вручную. Пока он не применён, открытый экземпляр может показывать предыдущий интерфейс.

## Техническая часть

C# / ASP.NET Core, .NET 10, Entity Framework Core, SQL Server, ClosedXML. Интерфейс на HTML, CSS и JavaScript. Для отдельной песочницы используется SQLite. Развёртывание — Ubuntu VPS, systemd, Docker и Nginx.

В операциях используются идентификаторы команд и версии записей; права проверяются на API. Серверные проверки написаны на xUnit, браузерные сценарии — на Playwright. Рабочая версия проходит ограниченный пилот; нагрузочная приёмка остаётся отдельной задачей.

## Этот репозиторий

Здесь находится статическая страница проекта. Серверное приложение хранится отдельно.

- `index.html` — содержание страницы.
- `styles.css` — оформление и адаптивная сетка.
- `assets/` — снимки интерфейса, шрифт Inter и его лицензия.
- `.nojekyll` — публикация файлов через GitHub Pages без обработки Jekyll.

Сборка страницы не требуется. Для локального просмотра:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`. На странице нет JavaScript, внешних виджетов и аналитических счётчиков.

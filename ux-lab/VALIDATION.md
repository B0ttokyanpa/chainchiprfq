# Проверка страницы — 08.11.2026

На локальной странице в Chromium пройден `check.cjs`:

- Поиск, отсутствие результатов, сброс, тип и подтип, видимые активные фильтры.
- Выделение черновиков, назначение закупщика и отмена; координата таблицы при появлении панели выделения не меняется.
- Архивирование и отмена действия.
- Создание черновика: ошибки пустых полей, ссылки на поля, перевод фокуса, сохранение введённых значений, добавление трёх строк.
- Медиана по умолчанию, предупреждение об аномальной цене, выбор поставщика, перенос цены/LT/DC в Анализ, возврат к медиане. Сумма трёх строк при медиане — 1625,00 USD; при выборе первого предложения для STM32F407VGT6 — 1575,00 USD.
- Сохранённые представления после перезагрузки; навигация клиентов и отчёта.
- Escape и возврат фокуса после диалога.
- Системная тема реагирует на изменение темы ОС; светлая, тёмная и reduced motion.
- Нет горизонтального переполнения документа на ширинах 320, 390, 744, 1024, 1600, 2048 CSS px. Таблица имеет собственную горизонтальную прокрутку и фокусируется клавиатурой.
- Нет необработанных ошибок JavaScript.

`contrast.cjs`: проверены 97 видимых текстовых фрагментов исходного основного экрана в каждой теме, с учётом цвета фона родительских элементов. Минимальный расчётный контраст — **4,78:1** в светлой и **6,57:1** в тёмной. Это проверка текста данного состояния, не полный автоматический аудит всех состояний и элементов WCAG. Полный результат — `contrast.json`.

Страница состоит из одного HTML, без запросов к серверным API, внешних библиотек, шрифтов и аналитики. Внешние ссылки на исследования открываются только при переходе пользователя.

Не проводились: исследование с сотрудниками, аудит экранным диктором, проверка Safari/Firefox, нагрузочный тест на 5000 позиций и полный WCAG-аудит. Представленные решения остаются гипотезами до проверки на реальных задачах. Рабочее приложение и его данные в ходе этой работы не изменялись.
